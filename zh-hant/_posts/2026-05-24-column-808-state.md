## 808國是什麼？

文字：mmr |主題：誕生於曼徹斯特地下俱樂部的 808 State 如何開創英國 techno 的未來，並將舞曲音樂轉變為一種知識和流行的表達方式。

1980年代末，來自美國的acid house在英國夜店迅速蔓延。特別是在曼徹斯特，這種熱潮並沒有僅僅作為一種舞曲音樂潮流而結束，而是成為一種新的城市文化。

處於這一切的中心的是808國。

他們不僅僅是一個 DJ 團體或只是一個 techno 樂團。他們是一支以獨特的英國風格重建誕生於芝加哥和底特律的舞曲音樂的樂團。

808 State 的音樂以俱樂部為導向，但又非常聰明。他將爵士、放克、實驗音樂、嘻哈、電子音樂的元素融入重複的節拍中，賦予機械律動獨特的溫暖感。

隨著他們的到來，「英國科技」的概念突然變成了現實。

## 曼徹斯特是個特別的城市

要了解808州，首先需要了解20世紀80年代末的曼徹斯特。

當時，曼徹斯特正在失去工業城市的動力，但新的文化能量正在地下湧動。

引領後龐克時代的工廠唱片公司和「The Haçienda」俱樂部就是這一點的象徵。

Haçienda 演奏了許多來自紐約、芝加哥和底特律的新舞曲。毒品文化、街頭情感和藝術情感融合在一起，創造了一個獨特的節日空間。

808國的成員們也在這樣的氛圍中開始了他們的活動。

### 主要成員

* 格雷厄姆·梅西
* 馬丁·普萊斯
* 傑拉爾德·辛普森
* 安德魯·巴克（Andrew Barker）後來加入

特別是 Graham Massey，他對爵士樂、放克音樂和實驗音樂有著深厚的了解，是支持 808 State 學術方面的重要人物。

傑拉德·辛普森後來以「一個叫傑拉德的人」的身份發展壯大，並成為英國迷幻屋歷史上的重要人物。

> 808 State 是一個將曼徹斯特特有的混亂和自由轉化為音樂的樂團。

## 小組組成和初始活動

808 State 大約在 1987 年開始活動。

當然，樂團的名稱取自 Roland TR-808。這不僅是一件樂器的名稱，更是當時舞曲本身的象徵。

他們最初是從唱片行 Eastern Bloc Records 周圍的社區發展起來的。

Eastern Bloc 不僅僅是一家商店，它還是 DJ、曲目製作人和俱樂部會員聚集的資訊交流中心。

當時，英國尚未建立成熟的技術生產環境。為此，808 State充分利用二手設備、廉價的鼓機和採樣器來創造自己獨特的聲音。

### 初始設備的特點

* 羅蘭TR-808
* 羅蘭TB-303
* 赤井取樣器
* 類比合成器
* 磁帶編輯

他們的早期作品深受芝加哥 house 和底特律 techno 的影響。

但同時，也蘊含著英國特有的陰雲密佈的氛圍與迷幻的感覺。

重要的是他們沒有按原樣演奏美國舞曲，而是將其轉化為英國風格。

> 808 State早期的唱片帶有一種將外來文化轉化為本土文化的獨特意識。

## 一場名為「新建」的革命

Newbuild於1988年發布，後來被重新評價為英國科技史上的重要作品。

當時這並沒有引起很大的轟動。不過，內容卻是極為先進的。

儘管這張專輯以迷幻浩室音樂為基礎，但它大膽地引入了長曲、氛圍發展、爵士樂情感和實驗。

尤其是，成為「太平洋國」原型的要素此時已經出現。

### 「新建」的特點

|元素|內容 |
| ------ | ----------- |
|節奏 |芝加哥四拍|
|聲音|環境空間感|
|取樣|源自爵士放克|
|成分|漫長而身臨其境|
|氛圍|英國多雲聲像|

當時的舞曲主要集中在單曲上，但《Newbuild》是一張專輯。

這也和後來的Warp作品以及IDM的流程有關。

<div class="mermaid">

這部作品表明，俱樂部音樂不僅僅是消費音樂，也可以是欣賞作品。

> Newbuild是一項重要的工作，為後來的智慧技術奠定了原型。

## 「太平洋國」的影響

正是「太平洋州」將808州推向了全球舞台。

這首歌於1989年發行，徹底改變了英國俱樂部音樂的歷史。

薩克斯風樂句、鳥鳴聲、流暢的和弦和輕柔的節拍。

與傳統acid house的侵略性不同，《Pacific State》有一種開放和漂浮的感覺。

這音樂讓人想起城市日出而不是深夜狂歡。

### 「太平洋國度」的創新

* 科技與爵士感的融合
* 環境聲音取樣
* 帶來一種放鬆的感覺
* 環境空間性
* 英國獨特的濕度感

這首歌也在英國排行榜上取得了成功。

從那時起，源自俱樂部文化的音樂開始接觸大眾。

《Pacific State》不僅是一首俱樂部熱門歌曲，更是一部展現了 20 世紀 90 年代電子音樂方向的作品。

> 憑藉這首歌，電子音樂開始被廣泛認為不僅僅是激進的舞曲。

## Warp 前後的電子音樂

808 State的存在也對Warp Records後來發展的知識電子路線產生了很大的影響。

20 世紀 90 年代初，俱樂部音樂變得更加碎片化。

* 鐵桿
* 碎拍
* 叢林
* 整合裝置製造商
* 環境技術

808 國家正處於十字路口。

尤其重要的是，它平衡了「跳舞用的音樂」和「聆聽用的音樂」。

這是英國電子音樂獨有的理念，後來催生了 Aphex Twin、Autechre、Boards of Canada 等公司。

808狀態不僅在商業上取得了巨大的成功，而且對後來的藝術家產生了巨大的思想影響。

> 它們是科技向「文化」的延伸。

## 「90後」與流行魅力的獲得

憑藉 1990 年的專輯《90》，808 State 在流行方向上走得更遠。

儘管如此，音樂性絕不是簡單的。

在保持複雜節奏、不規則結構、爵士感和取樣技術的同時，聲音變得更加開放。

《Cubik》和《Ancodia》等歌曲至今仍被認為是英國 techno 歷史上的代表歌曲。

### 「90」的要點

|歌曲名稱|特點|
| ----------- | ----------- |
|太平洋202 |漂浮感與環境品質|
|科必克 |電音節奏 |
|安科迪亞 |增強旋律感|
|眼鏡蛇波拉 |實驗性與俱樂部感|

808 State此時在地下音樂和流行音樂之間達到了非常高的平衡。

當許多電子音樂團體走向極端時，808 State 巧妙地走在中間地帶。

> 《90》成為英國電子音樂的傑作，融合了智力實驗和流行感性。

## 與馬德里的關係

808 State 也與「馬德里」文化有著深厚的連結。

Madchester 是 20 世紀 80 年代末至 90 年代初曼徹斯特週邊音樂、時尚和俱樂部文化的總稱。

Happy Mondays 和 The Stone Roses 等著名樂團背後都有著濃厚的舞曲文化。

808 State 是電子音樂的關鍵參與者。

他們的音樂也被搖滾聽眾所接受。

這在當時是非常特別的。

> 808 State 也是一個模糊了搖滾和科技之間界線的重要團體。

## 現場表現的演變

808 State 也堅定地致力於現場表演。

當時的現場電子音樂表演往往顯得單調的設備操作。然而，他們強調即興創作和表演感。

尤其是格雷厄姆·梅西 (Graham Massey)，他演奏多種樂器，並為他的現場表演帶來了爵士樂的感覺。

### ライブで重視された要素

* 即時編輯
* 即興創作
* 樣品變形
* 合成器操作
* 空間生產

這對後來的現場 techno 表達方式產生了很大的影響。

他們將電子音樂視為一種“變化的表演”，而不是“作為回放設備的現場表演”。

> 808 State的現場感覺成為後來現場電子表達的基礎。

## 1990年代的變化

20 世紀 90 年代中期，電子音樂界變得更加壯大。

銳舞文化變得商業化，俱樂部音樂進入主流。

808 State 繼續在各大聯盟運營，但要維持其早期的創新並不容易。

然而，他們並沒有喪失實驗精神。

在《Gorgeous》和《Don Solaris》等歌曲中，他接觸到了更廣泛的音樂性。

### 這一時期的特點

|改變 |內容 |
| ---| ------------ |
|音樂性|更著重旋律|
|生產|規模宏大|
|合作|多元化藝術家參與|
|聲像|精心製作 |

到 20 世紀 90 年代末，電子音樂已成為一種完全的全球文化。

808 State 是最早經歷這種變化的群體之一。

> 808國是從地下走向大工業的一代。

## 一位名叫格雷厄姆·梅西的天才

808 State 的創辦人 Graham Massey 不僅僅是一位電子音樂家。

他對爵士樂、融合音樂、當代音樂和實驗音樂有著濃厚的興趣，並參與了各種項目。

特別是，808 State 建構聲音和編曲感的能力使 808 State 獨一無二。

梅西在後來的幾年裡繼續與許多藝術家合作。

### 格雷厄姆·梅西的特點

* 了解爵士樂理論
* 聲音設計能力
* 即興創作的感覺
* 跨越多種流派
* 電子音樂與現場音樂的融合

梅西是 808 State 不僅僅是一個俱樂部單位的原因。

## 與一個叫傑拉德的人的關係

傑拉爾德辛普森 (Gerald Simpson) 作為 808 State 的早期成員發揮了重要作用。

後來他獨立，並以熱門歌曲《Voodoo Ray》成為英國迷幻屋歷史的代表。

傑拉德和 808 State 之間的關係是當時曼徹斯特文化的象徵。

在那個時代，社區和熱情比流派或歸屬更重要。

### 傑拉德的重要性

* 808早期國家聲音形成
* 酸屋蔓延
* 英國techno的早期形成
* 後來叢林的影響

> 當時在曼徹斯特，創造力更多是由社區而不是個人驅動的。

## 808 國家與日本

808 State很早就在日本很受歡迎。

1990 年代初，日本對 techno 和俱樂部文化的興趣開始迅速增長。

其中，808 State以「知性、精緻的電子音樂」形像被人們所接受。

它對日本的 techno 粉絲、俱樂部 DJ 和電子音樂製作人產生了巨大的影響。

### 日本受理

* 科技雜誌文化
* 拓展俱樂部文化
* 環境流行度
* 電子設備熱潮
* 澀谷系統聯絡點

特別是在20世紀90年代的日本，一種「欣賞俱樂部音樂的文化」正在形成。

808 State 非常適合這種氛圍。

尤其重要的是音調的選擇。

他們積極利用模擬設備特有的不穩定性和質感。

### 聲音特點

|樣品|有機排列|

與今天過度壓縮的 EDM 聲音不同，808 State 有一個空白。

這種留白創造了一種獨特的沉浸感。

將搖滾樂、爵士樂、嘻哈音樂和舞曲音樂相互切合而不分開的感覺在今天很常見，但在當時卻是極其先進的。

## 為什麼 808 狀態仍然很重要

電子音樂現已成為一個龐大的產業。

然而，當808 State成立時，techno還是一個未知的未來音樂。

他們試圖將這種未來不僅作為一種趨勢，而且作為一種文化。

808 State 的作品保留了創造新聲音的真正渴望。

在當今流派日益標準化的時代，這聽起來相當令人耳目一新。
