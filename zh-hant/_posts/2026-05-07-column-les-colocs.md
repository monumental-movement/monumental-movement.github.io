## 介紹

文：mmr｜主題：追溯20世紀90年代在魁北克爆紅的樂團Les Colocs的歷史、社會背景、音樂性、成員變遷和文化影響。

1990年代的加拿大魁北克。
法語世界的青年文化正處於重大轉折點。

MTV 文化的擴展。
垃圾搖滾趨勢。
美國流行文化的滲透。
另一方面，如何保護魁北克獨特的語言意識和地理文化一直是一個問題。

正是在這個時期，Les Colocs 出現了。

他們不僅僅是一支搖滾樂團。

有街上的味道，
伴隨著民間的故事，
融入非洲音樂的節奏，
吸收移民文化，
它唱出了魁北克社會的痛苦。

而且，聽起來也不是什麼說教，
它充滿了幽默、熱情和慶祝的感覺。

Les Colocs 的音樂有一種「公共生活」的氛圍，而不是「樂團」的氛圍。

事實上，樂團的名字「Colocs」是魁北克法語俚語，意思是「室友」。

他們的作品包括
都市的孤獨，
貧困，
癮，
工人文化，
多民族社會，
語言認同，
而生存本身的堅韌也被銘刻。

然而，音樂並沒有黑暗結束。

我會跳舞。
很有趣。
我可以尖叫。
我們可以一起唱歌。

Les Colocs 不是“有社會問題的人的音樂”，而是“擁抱社會本身的音樂”。

> Les Colocs 是一支慶祝性搖滾樂隊，是魁北克社會的縮影。

## 魁北克特殊音樂區

### 魁北克省作為法語區

要了解 Les Colocs，您首先需要了解魁北克文化。

在加拿大境內，
魁北克是一個極為獨特的地區。

主要語言為法語。
文化區也與英語區的加拿大不同。

自1960年代的「安靜革命」（Révolution stillle）以來，
魁北克的世俗化和民族認同的形成進展迅速。

音樂也不例外。

魁北克的創作歌手文化
法國香頌,
北美叉子,
凱爾特音樂,
勞動歌曲、
它是由當地民歌獨特的混合而成。

1970年代，Harmonia等進步民謠樂團開始流行，
1980年代，搖滾和流行音樂成為主流。

在這種趨勢下，在1990年代，
新一代雜食樂團正在蒙特婁市區興起。

Les Colocs 就是一個典型的例子。

### 蒙特婁是一座混合城市。

蒙特婁是
它被稱為北美文化最融合的城市之一。

法語區。
英語區。
海地移民。
非洲社區。
阿拉伯。
拉丁。

每種文化都是混合的。

Les Colocs 音樂中非洲節奏、雷鬼和藍調的自然存在很大程度上受到了城市環境的影響。

### 魁北克法語的重要性

《Les Colocs》的歌詞是：
不僅僅是標準法語。

魁北克獨特的口語
俚語，
含有大量工人階級語言。

這不僅僅是一種語言風格。

“你會用誰的語言唱歌？”
這是一種文化選擇。

在被英語流行文化包圍的同時，
我們敢於將當地語言的感覺凸顯出來。

Les Colocs 的受歡迎程度是
這也是魁北克人重申他們的「聲音」的現象。

> Les Colocs 的音樂反映了魁北克當地文化的複雜性。

## 成立前 ─ 安德烈「Dédé」福廷的背景

### 德德·福廷童年經歷

樂團的核心人物是安德烈·“Dédé”·福廷。

1962年出生於魁北克省諾曼丁。

儘管來自本地，
後來搬到蒙特婁。

在他看來，
當地社區之間的團結感，
城市生活的孤獨感都存在。

這與後來Les Colocs的世界觀有著直接的關聯。

### 街頭感和戲劇性

德德·福廷是
他不僅僅是一名歌手。

他有很強的戲劇意識。

直播中，
滑稽的動作，
誇張，
廣泛利用與觀眾的直接溝通。

另一方面，
歌詞中有深刻的社會觀察。

換句話說，他
他同時是個「小丑」和一個「社會觀察家」。

### 蒙特婁的活動

1980年代末，
在蒙特婁樂壇，
DIY 樂團文化正在擴展。

而非以大產業為主導，
住家，
酒吧，
共居社區，
街頭文化正在形成一種景象。

Les Colocs 是
這正是它的來源。

### 樂團名稱的含義

「Les Colocs」是「室友」。

這個名字是有像徵意義的。

在他們的音樂中，
源自於完美的專業精神，
公共生活充滿混亂的熱度。

音樂性也不太統一。

反而是雜七雜八的，
人際關係中的摩擦本身就轉化為能量。

> Les Colocs 的核心是將公共生活的混亂音樂化。

## Les Colocs 的形成與早期活動

### 1990年左右成立

Les Colocs 於 1990 年左右正式成立。

初始成員包括：

- 安德烈「德德」福廷
- 派崔克·埃斯波西托·迪那不勒斯
- 麥克·薩瓦茨基
- 塞爾吉·羅伯特
- 吉米·布爾戈林等人

成員組成不固定，
它會根據時間而變化。

### 街頭轟動與現場人氣

早期的 Les Colocs 是
他們的支持透過現場表演迅速擴大。

原因很清楚。

現場表演異常強勁。

觀眾參與類型。
合唱。
舞蹈。
混亂。
笑聲。
即興創作。

在他們的直播中，
龐克DIY精神和
慶祝的民間文化並存。

### 帕特里克·埃斯波西托·迪那不勒斯的存在

口琴家派崔克·埃斯波西托·迪那不勒斯
他是樂團早期的重要人物。

有海地血統，
他為 Les Colocs 帶來了多元文化的敏感度。

他的口琴，
也是布魯斯風格的，
聽起來也像移民音樂，
它也有一種街頭的感覺。

他的存在是
這將決定樂團未來的發展方向。

## 首張專輯和大眾人氣

### 「Les Colocs」 (1993)

1993年,
發行同名作品《Les Colocs》。

憑藉這部作品，
他們很快就在整個魁北克省廣為人知。

代表歌曲有：

- “主街”
- “莫韋特色”
- “朱莉”

### 「主街」的影響

「主街」是
這首歌被認為是一首講述農村地區衰落的歌曲。

年輕人外流。
當地經濟停滯。
空心。

這就是1990年代魁北克農村社會的現實。

然而，這首歌並不僅僅以悲觀結束。

懷舊與憤怒
執著同時存在。

### 與魁北克社會的聯繫

Les Colocs 受到廣泛支持的原因之一是因為
與其抽象化社會問題，
重點是將他描繪成一個特定的人。

城市。
酒吧。
失業了。
朋友。
癮。
勞動者。

他們的歌詞有一張「臉」。

這與觀眾建立了牢固的聯繫。

### 商業成功與異質性

有趣的是
雖然 Les Colocs 廣受歡迎，
同時，又是極其不同的。

它甚至不是適合廣播的流行音樂。
它也不是典型的岩石。
這甚至不是世界音樂。

儘管如此，它還是受到了廣泛的喜愛。

這是，
這也是因為魁北克社會想要「自己的故事」。

> Les Colocs 在描繪當地現實的同時引起了大眾的熱情。

## 帕特里克·埃斯波西托·迪那不勒斯的去世和轉折點

### 死於愛滋病

1994年,
帕特里克·埃斯波西托·迪那不勒斯死於愛滋病相關併發症。

這對樂團來說是一個決定性的事件。

當時，
愛滋病仍然是強烈偏見和恐懼的主題。

Les Colocs 是
我沒有隱瞞這個問題。

相當，
死亡和疾病被視為公共問題。

### 《十一月德霍爾》

派崔克去世後，
樂團製作了“Dehors Novembre”。

這首歌是
它已成為魁北克音樂史上最特別的作品之一。

在面對死亡的時候
很安靜，
詩意的，
有著深厚的感情。

不聳人聽聞。

相當，
聽起來就像是在與死者對話。

### 深化社會主題

這段時間過後，
Les Colocs 的歌詞具有更深的社會深度。

貧困。
孤獨。
拖。
自殺。
城市疏離。

但，
不要導致徹底的絕望。

音樂本身有節奏地擴展；
非洲音樂、打擊樂元素更加濃厚。

## Atrocetomique 與音樂擴展

### 1995年重要作品

1995年,
「Atrocetomique」的公告。

這部作品是
這是 Les Colocs 音樂擴張最明顯的專輯之一。

### 與非洲音樂的融合

尤其重要的是節奏方面。

西非政治。
打擊樂器。
集體合唱。

這些自然地融入岩石中。

作為當時的北美搖滾樂，
這是非常獨特的。

### 社會批判

從歌詞來看，
對城市議題和社會差距的關注將變得更加強烈。

Dédé Fortin 的歌詞是：
這不是新聞業。

不過，他的觀察力卻非常敏銳。

“誰被拋棄了？”
一直在看。

### 幽默與悲劇

Les Colocs 特點：
重要的是不要將其僅限於一場悲劇。

歌曲中總是夾雜著笑聲和諷刺。

這種感覺是
它也與魁北克文化特有的黑色幽默有關。

> Les Colocs 有能力將社會的沉重轉化為適合跳舞的音樂。

## 「Dehors Novembre」與內在世界

### 1998年作品

1998年,
《Dehors Novembre》發布。

這部作品是
較暗，
更加內省。

### 精神疲憊

在此期間，
也有人指出，Dédé Fortin 本人的精神狀況已經惡化。

工作內容包括
疲勞的感覺，
孤獨，
對自我毀滅的恐懼瀰漫。

但音樂依然優美。

### 與魁北克社會的關係

1990年代末，
魁北克社會也在改變。

獨立運動停滯不前。
經濟焦慮。
城市化。

Les Colocs 的作品有
這與這種時代感是同步的。

### “Tassez-vous de d'là”

這時期的代表歌曲之一“Tassez-vous de d'là”，
它被稱為一首混亂與能量共存的歌曲。

街頭感。
擁塞。
城市生活。
憤怒。

它們高速旋轉。

> 在Dehors Novembre，慶祝氣氛背後的疲憊凸顯出來。

## 德德·福廷之死

### 2000年的悲劇

2000年,
安德烈「Dédé」福廷結束了自己的生命。

他當時 38 歲。

本次活動是
震驚了整個魁北克文化界。

Dédé 不僅僅是一位搖滾明星。

他，

他的死具有重大意義。

死後，

這不僅僅是悲劇。

他們的音樂至今仍被人們聆聽。

活文化。
合唱文化。
當地文化。

因為它與所有這些都有聯繫。

## Les Colocs 的音樂特點

### 跨流派

Les Colocs 很難分類。

- 民謠搖滾
- 另類搖滾
- 世界音樂
- 藍調
- 雷鬼
- 香頌
- 打擊樂

這些同時存在。

### 合唱文化

在他們的音樂中，
集體合唱非常重要。

這不僅僅是一個裝飾。

“我不是一個人唱歌”
這個想法與此很接近。

### 強調節奏

Les Colocs 的一個關鍵要素是節奏。

不僅是典型的北美搖滾4拍，
使用了大量的圓形凹槽。

這在現場表演中引發了一種欣喜若狂的感覺。

### 評書

歌詞經常描述特定的人物。

從抽象思維出發，
畫街頭人物的肖像。

這與民間傳統有關。

> Les Colocs 將蒙特婁這座多元文化城市的音樂融合轉化為聲音。

## 對魁北克文化的影響

### 對後代的影響

Les Colocs 是
他對後來的魁北克音樂家產生了很大的影響。

以下幾點尤其重要。

- 當地語言表達
- 多元文化融合
- 與社會問題的聯繫
- 現場社區

### 重新定義“魁北克風格”

在他們之前，
「魁北克音樂」相對偏民謠嗎？
或者說，還有一個帶有濃鬱法國香頌氣息的圖像。

Les Colocs 就在那裡。
它帶來了城市的混合性。

### 人氣持續至今

即使現在，Les Colocs 的歌曲仍然
它在魁北克廣為流行。

許多歌曲代代相傳。

這裡有濃厚的合唱文化，尤其是在現場音樂會和當地活動中。

> Les Colocs 將魁北克音樂從「地域文化」拓展為「城市混合文化」。

## 為什麼 Les Colocs 仍然如此特別

Les Colocs 如此特別的原因在於
不是“完美的音樂”
重點是它是“現場音樂”。

很混亂。
粗糙的。
有時不穩定。

但在那裡，
有一個社區現實。

他們是
他們走了一條不同於北美商業搖滾成功模式的道路。

在不隱藏地點的情況下，
使用方言，
接受移民文化
他唱的歌涉及社會問題。

還有那個，
這聽起來像是慶祝活動，而不是佈道。

這就是為什麼它至今仍被人們聽到的原因。

Les Colocs 的音樂包括
有一種「我們將一起生存」的感覺。

這就是為什麼，
他們最終並不僅僅是一支 90 年代的樂團。

> Les Colocs は、共同体・都市・言語・痛みを丸ごと抱え込みながら鳴った稀有なバンドだった。
